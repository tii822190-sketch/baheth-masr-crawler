# قاعدة البيانات المحلية

قاعدة التشغيل الوحيدة هي `db/crawler.sqlite`. يجب أن تحتوي على ثلاثة جداول تطبيقية فقط:

- `sites`
- `site_pages`
- `index_results`

يهيئ `crawler/src/db.mjs` الجداول ويتحقق من سلامة SQLite. تحفظ GitHub Actions ملف القاعدة نفسه داخل المستودع بعد تشغيل العنكبوت أو الزاحف. لا توجد قاعدة staging أو مزامنة خارجية في مسار التشغيل الأساسي.
