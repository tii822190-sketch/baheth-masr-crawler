# مراجعة جودة اختبار الزاحف — خمسة مواقع

## ملخص التشغيل

تم تشغيل الزاحف يدويًا على خمسة روابط في قاعدة SQLite التجريبية. نجحت أربع استجابات HTTP، وفشلت واحدة بالمهلة. النجاح التقني في HTTP لا يعني أن محتوى الموقع صالح للفهرسة، لذلك يتضمن التقرير تقييمًا منفصلًا للجودة.

| الرابط | HTTP | الحالة | العنوان | النص | الروابط | التقييم |
|---|---:|---|---|---:|---:|---|
| `https://bardy.pages.dev/` | 200 | success | بردي — محرك البحث المصري | 0 | 0 | محتوى ديناميكي؛ يحتاج متصفحًا آليًا أو API للفهرسة |
| `https://baheth-masr-api.tii822190.workers.dev/` | 200 | success | فارغ | 0 | 0 | API وليس صفحة HTML؛ لا يُفهرس كرابط موقع |
| `https://www.alexu.edu.eg/` | 200 | success | 9NAGA ... | 1,263 | 1 | محتوى غير متوافق مع الجامعة؛ يحتاج فحص تحويل/اختراق |
| `https://www.cairo.gov.eg/` | 200 | success | الصفحة الرئيسية - بوابة محافظة القاهرة | 1,249 | 54 | نتيجة جيدة مبدئيًا؛ الرابط النهائي عربي `/ar/` |
| `https://asush.asu.edu.eg/` | — | network_error | فارغ | 0 | 0 | انتهت المهلة؛ يحتاج إعادة محاولة وسياسة timeout |

## الحقول المستخرجة

### بوابة محافظة القاهرة

- العنوان والوصف موجودان.
- تم توليد الخلاصة و`search_snippet`.
- تم استخراج 1,249 حرفًا من النص المنظف.
- تم استخراج 54 رابطًا، منها 34 داخلية و19 خارجية ورابط اجتماعي واحد.
- تم حفظ الرابط النهائي بعد التحويل إلى `https://www.cairo.gov.eg/ar/`.

### بردي

- العنوان موجود.
- الصفحة أعادت HTTP 200.
- المحتوى المعروض يعتمد على JavaScript، لذلك طلب HTTP لم يجد نصًا أو روابط.
- لا ينبغي اعتبار هذه النتيجة فارغة أو حذف الموقع؛ بل تُحوّل إلى مسار زحف ديناميكي لاحقًا.

### alexu.edu.eg

- HTTP 200، لكن العنوان والمحتوى إندونيسيان وغير متوافقين مع جامعة الإسكندرية.
- لا يجوز اعتماد النتيجة بناءً على HTTP فقط.
- يجب إضافة فحص تطابق النطاق والمحتوى واللغة، ووضع النتيجة في حالة مراجعة.

### asush.asu.edu.eg

- فشل الاتصال قبل استخراج البيانات.
- يجب إضافة retry محدود وزيادة timeout للمواقع البطيئة، مع عدم اعتبار الفشل دليلًا على أن الموقع غير موجود.

## الخطوات 1–5

1. **اختبار خمسة مواقع:** تم.
2. **مراجعة جودة الحقول:** تم؛ القاهرة جيدة مبدئيًا، وباقي الحالات لها أسباب واضحة.
3. **اختبار الصفحات الداخلية:** لم نفتح الصفحات بعد؛ الروابط اكتُشفت وحُفظت كمرشحين.
4. **تسجيل كل صفحة مستقلة:** لم يُفعّل بعد حتى نعتمد سياسة الصفحات.
5. **رصد مشاكل المواقع:** تم رصد المحتوى الديناميكي، API غير القابل للفهرسة، التحويل/المحتوى غير المتوافق، والمهلة.

## القرار

الزاحف مناسب للانتقال إلى مرحلة تحسين الجودة، وليس إلى الفهرسة النهائية بعد. التعديلات التالية مطلوبة قبل فتح الصفحات الداخلية:

- إضافة `content_quality` و`review_status` للنتيجة.
- اكتشاف المحتوى الديناميكي عند وجود HTML فارغ.
- منع فهرسة API كصفحة عادية.
- فحص تطابق النطاق النهائي مع النطاق المطلوب.
- فحص لغة ومؤشرات هوية الموقع.
- retry محدود للمواقع البطيئة.
